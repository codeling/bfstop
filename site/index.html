Brute Force Stop

Brute-force protection for Joomla! sites.

BFStop watches the logins of your Joomla! site. An IP address that fails to log in too often is blocked, for a time that grows with every repeated block, so password guessing gets nowhere. It comes as one package with a system plugin, a task plugin and an administration component, free and open source (GPLv3).

Download and install

  • Latest release on GitHub: install pkg_bfstop-<version>.zip in Joomla!'s System → Install → Extensions.
  • Also listed in the Joomla! Extensions Directory.
  • BFStop 2 needs Joomla! 5.4 or 6 and PHP 8.1 or later. Sites on Joomla! 4 or 5.0–5.3 stay with BFStop 1.5, which is what their updater offers.
  • Once installed, Joomla! offers updates itself: the update server of BFStop is this site.

For the curious: the update server

Joomla! sites with BFStop ask update.xml and update-pkg.xml on this site for new versions. They are generated from the releases published on GitHub (never from test releases), and offer each site only a version that runs on its Joomla! version.
